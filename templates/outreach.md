# 触达话术模板

占位符：`{{name}}` 博主昵称 · `{{work}}` 对方真实代表作标题 · `{{brand}}` 品牌名 ·
`{{product_pitch}}` 一句话卖点 · `{{demo_topic}}` 实测向选题示例（如"用 AI 一天搭出个人网站"）。运行时自动填充；生成的清单每份顶部附**发送纪律**
（每日新私信 ≤ 上限、发前先点赞+走心评论、首条不带链接）。发送永远由人手动完成。

## A · 首次触达（小红书/抖音通用）

```
哈喽～刚看完你那篇《{{work}}》，我们觉得非常出色并且实用！
自我介绍下：我们是 {{brand}}，{{product_pitch}}
感觉和你的选题路线蛮搭，想问下你这边接商务合作吗？方便的话想请教图文/视频的
报价和档期～我们可以提供现成的演示素材包，拍起来很省事。
```

## B · 询价 + 要数据（对方表示愿意接单后）

```
太好了！跟你确认几个信息哈：
1）图文和视频分别的报备一口价（走蒲公英/星图的价格）；
2）近30天后台数据方便发下吗？小红书想看笔记曝光中位数+粉丝画像（地区/年龄），
   抖音想看播放中位数和完播率；
3）最近可排的档期；
4）价格和数据合适的话，我们走完内部审批就锁档期，一般2-3个工作日。
```

## C · 跟进（3天未回，只跟进一次，带新信息不复读）

```
{{name}} 冒泡下～之前的合作邀约不知道你有没有看到。补充个信息：素材我们都备好了，
选题可以做成「{{demo_topic}}」这种实测向内容，你套自己的风格就行。
有兴趣随时回我，没兴趣也完全 OK～
```

## D · 议价（报价超预算时）

```
实话说这个报价超了我们这轮单条的预算上限。不过我们很想跟你合作，看这样行不行：
这轮先按 {{X}} 做一条，素材我们全包、你制作成本很低；数据好的话下一轮按你刊例价加投；
另外把内容授权转载到我们官方账号和项目页，都署名带你主页。你看能接受不？
```

## E · 合作确认 + 内容 Brief（签约后发）

```
合同/报备今天走起。内容上几个小要求，其他都按你风格来：
① 核心画面：从「一句话输入」到「生成完整成品」的过程（我们提供录屏，或你自己跑一遍，几分钟）；
② 必须出现：GitHub 搜「{{repo_slug}}」+ 两条安装命令（一闪而过即可），顺口一句"觉得好用去点个star"；
③ 发布前给我们看一版（只核对命令/名称等事实，不动风格）；发布后第7天发一次后台数据截图。
素材包这就发你。
```

## F · 婉拒备库（报价过高/数据不符，不烧桥）

```
谢谢报价！这轮预算有限，先把你记进优先合作清单，下一轮预算批下来第一时间找你～
另外你本来就有相关选题排期的话，随时找我们拿素材包，开源项目随便用，不涉及商务也OK。
```

## H · 评论区置顶口令卡片（发给博主随内容置顶，防站外链接限流）

```
不想翻链接的：GitHub 搜「{{repo_slug}}」（开源免费，两条命令装进 Claude）；
不想装的：浏览器打开 {{web_fallback}} 直接生成（前期免费）。
```
