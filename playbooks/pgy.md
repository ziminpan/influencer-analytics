## 这是什么、为什么优先

蒲公英 = 小红书官方达人商单平台（pgy.xiaohongshu.com）。品牌号登录后可以**自助**看到
达人的官方后台级数据——不用再问博主要截图。它是估算精度阶梯的新顶层：
**蒲公英官方值 > 博主后台截图 > 逐账号抽样 > 类目先验**。
对账之后，整库数据从"估算可信"升级为"官方可审计"。

## 前置

- 公司蒲公英品牌号已开通，当前浏览器已登录 pgy.xiaohongshu.com
  （登录态检查：打开首页看右上角是否显示品牌账号名；未登录停下请用户处理）。✅ 实测有效
- 只查询**已入库/候选**博主，不做全站漫游式浏览。

## 实测流程（2026-07-17 定稿）

1. **入口**：`/solar/pre-trade/note/kol`（找博主→笔记博主广场），搜索框左侧切到「**搜昵称**」。
2. **搜索**：三击全选输入框 → 输入昵称 → 点放大镜（输入框右端）。下拉联想可无视。
3. **进详情（免开标签页法）**：结果行点击会 `window.open` 新标签，批量采集会开一堆标签。
   实测可拦截捕获：
   ```js
   window.__cap=null;                                   // ← 每次必须先重置，否则读到上一位的残值
   const NAME='目标昵称';
   let cands=[...document.querySelectorAll('div,span,a,p')]
     .filter(e=>(e.innerText||'').replace(/\s+/g,'')===NAME && e.querySelectorAll('*').length<8)
     .filter(e=>{let p=e,d=0;while(p&&d<10){if(/添加合作/.test(p.innerText||'')&&p.innerText.length<800)return true;p=p.parentElement;d++}return false});
   cands.sort((a,b)=>a.querySelectorAll('*').length-b.querySelectorAll('*').length);
   const leaves=cands.length?[...cands[0].querySelectorAll('*')].filter(e=>e.childElementCount===0):[];
   const orig=window.open; window.open=u=>{window.__cap=u;return null;};
   try{ for(const t of [...leaves,...cands]){
     ['mousedown','mouseup','click'].forEach(ev=>t.dispatchEvent(new MouseEvent(ev,{bubbles:true,cancelable:true,view:window})));
     if(window.__cap)break; } } finally { window.open=orig }
   (window.__cap||'').match(/blogger-detail\/([0-9a-f]+)/)?.[1]
   ```
   要点：昵称会被搜索词**高亮拆成多个叶节点**（如 "AI"+"博士嗨嗨"），精确匹配单叶必失败——
   用「去空白后整体等于昵称的最小容器」，且**从叶子片段开始**逐个试点击（handler 挂在内层）。
4. **直达**：详情页 URL = `blogger-detail/<小红书userId>`，与 C 端主页 id 同一个。
   **库内已有主页链接的博主直接拼 URL 打开，跳过搜索**（省一半访问量）。
5. **详情页提取**：等 6-8 秒渲染后，对 `document.body.innerText` 做**标签锚定正则**
   （不要依赖 class，PGY 类名是构建产物）。可用标签：
   `粉丝数 / 获赞与收藏 / 图文笔记一口价 / 视频笔记一口价 / 曝光中位数 / 阅读中位数 /
   互动中位数 / 近7天活跃天数 / 邀约48小时回复率 / 粉丝量变化幅度 / 发布笔记N篇 /
   数据更新至 / 小红书号 / 性别分布 / 年龄分布 / 国内最高的三个省份 / 苹果用户占比 /
   用户最感兴趣的内容类型`。
6. **两个口径都要**：笔记数据卡右上有「日常笔记 / 合作笔记」toggle（JS 点叶节点文本即可切换），
   日常口径抓完点「合作笔记」再抓一遍。**合作口径是商单预期的直接锚点**。
7. 达人数据区**截图留档**（原始凭据，同 raw_samples 思想）。
8. 官方值回库：official_reads_median / expected_exposure / cpm 联动；AD 备注写"蒲公英官方值 YYYY-MM"。
9. 凑够 ≥8 个「官方阅读 vs 库内估算」对照后：比值中位数 → 修正 config 的
   `xhs_read_multiplier`（人工确认后写回，CHANGELOG 记一行）。


## 发现（Discovery）· 用筛选器选博主（2026-07-17 实测通过）

比 C 端关键词盲搜高效一个量级，但**只覆盖入驻博主（≥1000粉且开通接单）**——
未入驻 KOC 层仍需 C 端关键词搜索，两条腿并行。

流程（实测）：
1. 博主广场 `/solar/pre-trade/note/kol`，博主类目行点「展开」→ 选类目（如 科技数码）。
   类目 chips 在窄窗口下部分隐藏，**先展开再点**，点完看底部筛选条确认
   （出现「博主类目：科技数码-全部 ×」才算生效）。
2. 粉丝画像 → 粉丝量：预设档（0.1万~0.5万 / 0.5万~1万 / 1万~10万…）或自定义区间。
   ⚠ 自定义**下限输入实测未生效**（chip 显示「不限-10000」），上限生效；
   下限反正被入驻门槛 1000 兜底，影响不大，但别依赖它。
3. 可叠加：日常笔记（阅读中位数/互动中位数）、合作表现（合作报价区间）、
   常规剔除（剔除已合作/已邀约博主）。组合即我们的硬性门槛。
4. 结果行提取（**不要**依赖「添加合作」按钮文本——窄窗口下操作列是独立固定 DOM）：
   ```js
   // 头像锚定法：向上爬到文本长度 30-600 的行容器
   const seen=new Set();const rows=[];
   [...document.querySelectorAll('img')].forEach(img=>{
     if(!/avatar|sns-img|picasso/.test(img.src||''))return;
     let p=img,d=0;
     while(p&&d<8){const t=(p.innerText||'').trim();
       if(t.length>30&&t.length<600&&/粉丝|期待与|\d{3,}/.test(t)){
         const k=t.slice(0,20);if(!seen.has(k)){seen.add(k);rows.push(p)}break}
       p=p.parentElement;d++}});
   ```
   每行文本含：昵称|地域|人设|类目|粉丝数|阅读中位|互动中位|¥报价起。
   行内 id 捕获沿用 window.open 拦截法（对行内叶子逐个 dispatch click）。
5. 分页：每页 20 行；翻页一次算一次页面访问，**遵守 pacing**；
   「推荐 N 位博主」计数在 5000/10000 处封顶，是估算展示，不代表查全率。
6. 候选去重对库（编号/PGYid），新增者走原初筛→入库 SOP。

## 已知事实与坑（含 2026-07-17 实测新增）

- 达人入驻门槛粉丝 ≥1000：搜不到 = 未入驻或粉丝不足 → 保持估算值，notes 标"未入驻蒲公英"。
- **未入驻形态**：详情页可打开但报价区显示"暂未入驻"、无数据概览/画像；
  **笔记案例区仍展示官方单篇阅读数**——未入驻博主的重要副产品，可作校准样本与谈价参考。
- **合作口径空数据坑**：近30日无品牌合作时合作卡显示"-"，但隐藏的日常卡仍在 DOM 里，
  正则会**误匹配到日常值**。先测 `/暂未与品牌合作|暂无合作笔记数据/` 再取值。
- **口径差异**：搜索结果列表的"阅读中位数（日常）"与详情页数值不同（时间窗不同），
  **以详情页为准**（有"优于同行%"上下文且与数据更新日期绑定）。
- 刊例价普遍高于私聊底价，但**反例存在**（实测有博主私聊价比刊例高 56%）——两个数都留，
  刊例是还价的官方锚点。
- 走蒲公英报备的内容不限流、可投流；私下合作有限流风险——这正是
  `budget_planned = 报价 × (1 + platform_fee_rate)` 当初的设计原因。
- **工具层**：浏览器 JS 返回值含完整 URL/连续 24 位 hex 会被安全过滤器拦截（[BLOCKED]），
  id 用 `split('').join(' ')` 空格间隔返回再拼接。
- **窄窗口固定列拆分**：视口 <1100px 时结果表「操作」列变独立固定 DOM，行容器文本
  不再含「添加合作」——行检测一律用头像锚定法（见 Discovery 第 4 步）。
- **昵称搜索前先重置筛选**：筛选条件与昵称搜索是 AND 关系，忘了重置会搜不到
  （粉丝过滤会把目标挡掉）；点底部筛选条「重置」。
- **搜索输入框必须在页面顶部可见时再点击输入**，页面滚动中 type 会丢失焦点。
- **首访引导弹窗**（1/5、1/3 步）会盖住卡片，连点「下一步/我知道了」清掉再截图。
- **风控实测**：27 博主 ×2 页面（搜索+详情），间隔 ≥45s + 每 8 人休 3 分钟，
  全程零验证码零"频繁"提示。单日 60 页上限内很安全。
- 邀约48小时回复率是**触达渠道选择信号**：私信无回应但回复率 >85% 的博主，
  改走蒲公英官方邀约大概率能联系上（实测 Rico有三猫 96.4%、Esther不二 87.5%）。
